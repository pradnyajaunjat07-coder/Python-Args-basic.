# Python-Args-basic.
*args and **kwargs points are covered. 

The programs in this repository cover basic Python concepts such as:

- Functions
- `*args` (Variable-Length Arguments)
- `**kwargs` (Keyword Arguments)
- Tuples
- Dictionaries
- Loops
- Conditional statements
- Finding the largest number
- Counting even numbers
- Working with student marks
- Calculating total marks

## Programs

| Program | Description |
|--------|-------------|
| `Q1.py` | Function using `*args` to find the largest number without using `max()` |
| `Q2.py` | Function using `*args` to count the number of even numbers |
| `Q3.py` | Function using `**kwargs` to print only the values |
| `Q4.py` | Function using `**kwargs` to calculate total marks |
| `star-kwarg-ex.py` | Example of using `**kwargs` with a dictionary |
| `both-args-ex.py` | Example using normal arguments, `*args`, and `**kwargs` together |

## Concepts Practiced

### *args
`*args` allows a function to accept multiple positional arguments.

For example, the repository includes a function that accepts multiple numbers and finds the largest number without using the built-in `max()` function. :contentReference[oaicite:0]{index=0}

Another program uses `*args` to count how many of the given numbers are even. :contentReference[oaicite:1]{index=1}

### **kwargs
`**kwargs` allows a function to accept multiple keyword arguments.

The programs demonstrate how to:

- Print only the values from keyword arguments
- Calculate total marks
- Work with dictionary data

For example, the total marks program receives subjects and marks as keyword arguments and calculates their total. :contentReference[oaicite:2]{index=2}
